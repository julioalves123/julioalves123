Metodologia V2 - Melhorias de Precisão

  • Índices: NDVI = (B08-B04)/(B08+B04) + SAVI (L=0.5) reduz solo + NDWI água
  • Filtragem: Bilateral preserva bordas (win=7, sigma_color=0.1)
  • Hysteresis: Semente high Otsu*1.15 + crescimento low Otsu*0.85 via reconstrução morfológica
  • Morfologia: Reconstrução + filtro forma (solidity>0.25, eccentricity<0.995, compactness>0.02)
  • Gradiente RGB: Sobel, borda vegetação ajustada para seguir bordas reais, <25% mudança área
  • Vetorização: Marching squares sub-pixel + Chaikin 2 iterações + simplify 0.25m + buffer round 1m
  • Anti-quadriculado: Suavização vetorial + snapping a gradientes reais

ℹ️ Como funciona? V2 Alta Precisão

  1. KML: Parser XML robusto, Polygon/MultiPolygon/holes, área Web Mercator
  2. Sentinel-2 V2: Produção busca L2A real <10% nuvens via Copernicus STAC. Demo offline V2 ultra-realista: fractal multi-oitavas, domain warping, vegetação orgânica thresholded (não círculos), clareiras, rios, 3 tipos solo, sombreamento topográfico.
  3. NDVI+SAVI: NDVI filtrado bilateral preserva bordas + SAVI L=0.5 reduz solo + NDWI água. Hysteresis high= Otsu*1.15 semente, low= Otsu*0.85 crescimento via reconstrução morfológica.
  4. Precisão: Morfologia reconstrução + filtro forma (solidity, eccentricity, compactness) remove estradas/cercas/ruído + refinamento gradiente RGB Sobel (<25% mudança área) para bordas seguirem limites reais visíveis.
  5. Vetorização V2: Marching squares sub-pixel, Chaikin 2 iterações, simplify 0.25m, buffer round 1m, make_valid, unary_union. Elimina quadriculado e preserva fidelidade aos limites reais.
  6. Saídas: KML vegetação + PDF laudo V2 com metodologia detalhada, áreas, confiança, mapas RGB/NDVI/overlay/final.
